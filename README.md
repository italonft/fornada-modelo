# Fornada

Preço certo, encomendas, lista de compras e cardápio online para quem vende comida feita em casa.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/italonft/fornada-modelo)

Na tela da Cloudflare:

- Dê ao repositório novo um nome diferente deste, por exemplo `fornada-app`, e marque para ele ser privado.
- Deixe a Cloudflare criar um banco de dados novo.
- Em `ADMIN_PASSWORD`, invente a senha do seu painel do dono e anote.
